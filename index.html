The problem

Long conversations quietly degrade.

Early instructions fade

The rules you set at the start stop being followed as the conversation grows.

Important context gets buried

Key details get lost under everything that came after them.

Answers start contradicting earlier ones

How it works

One badge, four jobs

Live in v0.2

Context Meter

Live estimates of message count, token usage, and context window pressure, right on the page.

Live in v0.2

Context Health Score

A single 0–100 risk score, weighing token pressure, instruction decay, topic drift, contradiction risk, and complexity together.

Privacy

Built to never see your conversation

Everything runs on your device

Parsing, scoring, and estimates all happen locally in the browser — nothing about your conversation is sent anywhere.

No account, no server

ContextVitals has no backend that your chats pass through.

Every number says "estimated"

ContextVitals can't see a model's real internal context state, so it never claims to — only ever estimates.
